# TrailGear & Harry's store

Интернет-магазин туристического снаряжения. Учебный проект на чистом HTML, CSS и JavaScript.

## Возможности

- Каталог из 34 товаров с поиском и подгрузкой по кнопке
- Корзина с сохранением в localStorage
- Слайдер на главной с автопрокруткой
- Модальное окно с подробной информацией о товаре
- Адаптивная вёрстка под десктоп, планшет и телефон
- Бургер-меню на мобильных

## Стек

- HTML5
- CSS3 (Flexbox, Grid, CSS-переменные)
- JavaScript (ES6+)
- localStorage — хранение корзины
- Intl.NumberFormat — форматирование цен

Без библиотек, фреймворков и сборки.

## Структура проекта

```
.
├── index.html
├── style.css
├── main.js
└── products.js
```

- `index.html` — разметка страницы
- `style.css` — стили и адаптивность
- `main.js` — логика приложения
- `products.js` — данные товаров

## Запуск

Клонировать репозиторий и открыть `index.html` в браузере. Либо запустить локальный сервер:

```
python -m http.server 8000
```

После этого страница будет доступна по адресу `http://localhost:8000`.
